Cards of Factoria — Desktop Launcher
=====================================

HOW TO PLAY:
  Double-click "Cards of Factoria.vbs"

That's it. The game opens in a windowed app — no browser tabs, no URL bar.

REQUIREMENTS:
  - Windows 10 or 11
  - Microsoft Edge (pre-installed on every Windows since 2020)
  - Internet connection

TROUBLESHOOTING:
  - If Windows asks "How do you want to open this file?",
    pick "Microsoft Windows Based Script Host".
  - If nothing happens at all, just open the game in your browser:
    https://cards-of-actoria.onrender.com

NOTE:
  The game runs entirely online. This launcher is just a shortcut
  that opens the game in a clean app window. No installation needed.
